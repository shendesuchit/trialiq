# Investigator Experience

## Main journey

```text
Study selection
  -> Question
  -> optional HITL
  -> Answer
  -> Studies
  -> Connections
  -> Evidence
  -> Prepare report
  -> PDF
```

## Answer

The investigator sees the conclusion first, together with grounding/generation context and paths into supporting workspaces.

## Studies

Used to review the analysed related studies, filter them and compare source-backed timing/enrollment data.

## Connections

Explains why the analysed studies are related through canonical:

- Conditions;
- Interventions;
- Sponsors.

The technical node-link explorer is optional progressive disclosure.

## Evidence

Shows source-backed records, validation state and provenance information.

## Report

The investigator selects which result sections leave TrialIQ and downloads a deterministic PDF.

## UX guardrail

Visual references can influence styling, but they must not silently replace TrialIQ functionality such as branch selection, graph controls, table/network parity or evidence access.

## Recommended visual

Use `07-investigator-ui-flow.mmd`.
