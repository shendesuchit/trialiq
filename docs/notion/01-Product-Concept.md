# Product Concept

## The problem

Clinical-trial investigation often starts with one study but quickly becomes a relationship and evidence problem:

- Which other trials are meaningfully connected?
- What exactly connects them?
- Which comparisons can be supported by loaded source data?
- Which result set is small enough to review automatically?
- Where should an investigator intervene?
- Can the final explanation be traced to source-backed evidence?

A keyword result list does not solve that whole workflow.

## TrialIQ's product thesis

TrialIQ separates language intelligence from evidence truth.

**LLMs are used for:**

- understanding the investigator's question;
- producing a readable grounded synthesis.

**Deterministic TrialIQ code is used for:**

- graph retrieval;
- traversal bounds;
- metric calculations;
- candidate review policy;
- evidence validation;
- report generation.

## What the user gets

- direct trial lookup;
- guided related-study investigation;
- source-backed study comparisons;
- human control over broad evidence sets;
- explainable graph connections;
- evidence and provenance review;
- a deterministic PDF report.

## Stable-demo boundary

TrialIQ is an evidence-support technical preview, not a production clinical-decision platform.
